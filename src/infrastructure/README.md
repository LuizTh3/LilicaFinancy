# Infraestrutura

Área reservada a futuras integrações e repositórios que encapsularão persistência.
A interface não deve acessar SDKs diretamente e o domínio não deve depender desta área.

Não há conexão Firebase, SDK, autenticação ou repositório simulado nesta entrega.
A futura integração exigirá sua própria especificação, esquema, regras de autorização,
contrato completo de firestore.rules e validação de isolamento conforme a constituição.
